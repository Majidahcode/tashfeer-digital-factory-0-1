  3. `homepage-customer-phrases` (`dd5f0ce`): العميل على الشاشات الكبيرة، والعبارات الثلاث على الصفحة كلها، وشريط التمرير.

  5. على الفرع نفسه: **صورتك المرجعية للبوابة** (2026-10-23)، والدردشة داخل فتحتها، وضبط التخطيط والعبارات عليها. التفاصيل في `PROGRESS.md` §1، والقرارات D25–D33 في `PHASE_1_REPORT.md`، واللقطات في `docs/review/reference-portal/`.
- **التحقق المحلي** للفرع: lint وtypecheck والوحدات والبناء وChromium بسبعة أحجام (الأرقام في `PROGRESS.md` §3). **Firefox وWebKit لم يُشغّلا عليه بعد**: يعملان في CI فقط، وCI لا يعمل إلا بعد الرفع.

**المطلوب منك:**
1. مراجعة لقطات `docs/review/reference-portal/`، ثم الموافقة الصريحة على رفع الفروع وفتح طلب دمج، أو ذكر التعديلات.
2. المقايضة على 1280–1440 (D29): بوابة أعرض مقابل تشفير أصغر بـ10% على 1440، أو إبقاء تشفير بحجمه وبوابة أصغر بنحو 3%.
3. ملفات الحلقة السابقة (`assets/derived/portal/luminous-portal-ring.*`): إبقاؤها مرجعًا أم حذفها.
4. التحقق من النفق على جهازك: الوضع من الطرفية، ثم الأمر التشخيصي على الرابطين.
5. من الجولة السابقة: الإملاء «بطيء» أو «بطيئ»، وفسحة الجوال بين الشخصيتين والعنوان (D23).
6. لاحقًا: قرارات المراحل التالية DEC-03 وDEC-04 وDEC-05 وDEC-06 وDEC-09…DEC-16.

**إن كانت البيئة جديدة:**
- انسخ المستودع (`main` عليه المرحلة 1)، ثم أعد الفروع من ملف patch الأخير، وفيه الالتزامات الخمسة بالترتيب:
  ```bash
  git checkout -b homepage-customer-phrases main
  git am --committer-date-is-author-date homepage-customer-phrases-5-commits.patch
  git branch chat-proportions HEAD~4 && git branch homepage-refinement HEAD~3
  ```
  البصمات تطابق «نقاط التوقف» في `PROGRESS.md` إن كانت هوية الملتزِم في git هي نفسها؛ وإلا يتطابق المحتوى وتختلف البصمات.
- Firefox وWebKit لا يُنزَّلان في بيئة التطوير. وإن لم يطابق Chromium المثبت إصدار Playwright 1.56، فانظر `PROGRESS.md` §6.
