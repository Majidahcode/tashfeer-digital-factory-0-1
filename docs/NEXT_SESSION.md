# ملخص الاستئناف — الجلسة القادمة

**أين توقفنا (2026-10-23 مساءً):**
- المرحلة 0 مكتملة. المرحلة 1 **مدموجة في `main`** بموافقتك (طلب الدمج #1، التزام الدمج `2b34ef2`)، وCI على `main` ناجح بمهمتيه (التشغيل 39870686582؛ فيه اختبار متقلب واحد نجح عند الإعادة: P1-10 على `webkit-390`).
- **بعد الدمج ثلاثة فروع محلية، غير مرفوعة وغير مدموجة، كل منها في ملف patch سُلّم لك:**
  1. `chat-proportions` (`f1edb7b`، فوق `main`): الدردشة تأخذ مساحة البوابة، وأيقونات المرفقات وEnter أصغر.
  2. `homepage-refinement` (`e714c40`، فوق الأول): خط الدردشة وصورتها، و«معاينة تصميم — غير مفعّل»، وبوابة أكبر على الشاشات العريضة، وإضاءة 01–05 كل 10 ث.
  3. `homepage-customer-phrases` (فوق الثاني): العميل على الشاشات الكبيرة تحت العنوان و«كيف نبدأ؟» ووجهه مكشوف، والعبارات الثلاث موزعة على الصفحة كلها، وشريط التمرير بهوية النيون. التفاصيل في `PROGRESS.md` §1 («بعد الدمج»)، والقرارات D21–D24 في `PHASE_1_REPORT.md`، واللقطات في `docs/review/customer-phrases/`.
- **التحقق المحلي** لـ `homepage-customer-phrases`: lint وtypecheck والوحدات والبناء وChromium بسبعة أحجام، كلها ناجحة (الأرقام في `PROGRESS.md` §3). **Firefox وWebKit لم يُشغّلا عليه بعد**: يعملان في CI فقط، وCI لا يعمل إلا بعد الرفع.

**المطلوب منك:**
1. مراجعة لقطات الفروع الثلاثة، ثم الموافقة الصريحة على رفعها وفتح طلب دمج، أو ذكر التعديلات.
2. حسم نقطتين في الفرع الثالث:
   - الإملاء «بطيء» (كما في نموذجك والموجّه الرئيسي) أو «بطيئ» (كما في طلبك).
   - إبقاء فسحة العبارات بين الشخصيتين والعنوان على الجوال، أو حذفها والاكتفاء بفسحتين (D23).
3. لاحقًا: قرارات المراحل التالية DEC-03 وDEC-04 وDEC-05 وDEC-06 وDEC-09…DEC-16.

**إن كانت البيئة جديدة:**
- انسخ المستودع (`main` عليه المرحلة 1)، ثم أعد الفروع من ملف patch الأخير، وفيه الالتزامات الثلاثة بالترتيب:
  ```bash
  git checkout -b homepage-customer-phrases main
  git am --committer-date-is-author-date homepage-customer-phrases-3-commits.patch
  git branch chat-proportions HEAD~2 && git branch homepage-refinement HEAD~1
  ```
  البصمات تطابق «نقاط التوقف» في `PROGRESS.md` إن كانت هوية الملتزِم في git هي نفسها؛ وإلا يتطابق المحتوى وتختلف البصمات.
- Firefox وWebKit لا يُنزَّلان في بيئة التطوير. وإن لم يطابق Chromium المثبت إصدار Playwright 1.56، فانظر `PROGRESS.md` §6.
