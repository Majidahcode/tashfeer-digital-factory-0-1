# حزمة بناء النسخة الأولى لمصنع تشفير

## الملفات الموجودة
- `01-reference/current-tashfeer-prototype.html`: ملف النموذج الحالي كما رفعه المستخدم. لا تعدّل هذه النسخة الأصلية مباشرة؛ انسخها إلى مشروع العمل أو احتفظ بها كمرجع.
- `01-reference/card-style-reference-01-02-03.png`: مرجع بصري لأسلوب البطاقات المرقمة والتوهج المتدرج.
- `02-assets/characters/`: صور شخصية تشفير والعميل الجالس المستخرجة من HTML. افحص الشفافية والحواف قبل تحريكها.
- `02-assets/portal/`: أصل صورة إطار/حلقة البوابة المستخرج من HTML. نافذة الدردشة نفسها الأفضل أن تبنى كـHTML/CSS ومكوّنات فعلية، لا كصورة ثابتة.
- `02-assets/brand/tashfeer-brand-mark.png`: قصّ شفاف من صورة تشفير الأصلية لاستخدامه كعلامة اللوقو بجانب كلمة «تشفير».
- `01-reference/card-style-reference-01-02-03.png`: المرجع النهائي للألوان والدرجات والبطاقات الزجاجية.
- `02-assets/agents/`: الصور المضمنة في خريطة الوكلاء داخل HTML الحالي.
- `03-docs/MASTER_PROMPT_CLAUDE_PRO_MVP.md`: البرومبت الرئيسي المحدث.
- `03-docs/BRAND_MOTION_ADDENDUM_AR.md`: ملحق عربي لآخر توجيهات الهوية والخلفية.

## تنبيه الأصول
يحتوي HTML الحالي على صور مضمّنة لسبعة وكلاء فقط: الباحث، مصمم UX/UI، معماري البرمجيات، المطور الأمامي، المطور الخلفي، قاعدة البيانات، اختبار الجودة. الصور المستقلة لمدير المنتج، محلل المتطلبات، الأمن السيبراني، الأداء، والعمليات غير موجودة في خريطة الصور المضمّنة الحالية. أرفق هذه الصور الخمس بشكل منفصل إلى Claude، وكذلك أي صور أصلية أحدث لديك.

## طريقة الإرسال إلى Claude Code
1. افتح المستودع المحلي الذي تم تنزيله من GitHub داخل VS Code أو Terminal حيث يعمل Claude Code.
2. ضع هذا المجلد داخل المشروع أو أبقه بجانبه، ولا ترفع الأسرار أو `.env` إلى GitHub.
3. ابدأ بإرفاق/إتاحة ملف `MASTER_PROMPT_CLAUDE_PRO_MVP.md` له واطلب منه قراءة كامل البرومبت أولًا.
4. اطلب فحصًا للملفات ثم خطة تنفيذ قبل تغيير البنية أو حذف أي كود.
5. أرفق صور الروبوتات المتبقية كملفات منفصلة مع أسماء واضحة.
6. لا تطلب نشرًا حيًا قبل إعداد مفاتيح API وقاعدة البيانات وتخزين الملفات وبيئة sandbox وأسرار النشر.

## قائمة ملفات ينبغي توفيرها قبل التنفيذ المتقدم
- [ ] الصورة المعتمدة النهائية للواجهة الرئيسية أو لقطة شاشة عالية الدقة.
- [ ] صورة تشفير الأصلية الشفافة أو مجسم 3D rigged بصيغة GLB/GLTF/VRM مع حركات idle/listening/speaking/gesture/walk إن كانت حركات رأس/ذراع واقعية مطلوبة.
- [ ] صورة العميل الجالس بجودة عالية وشفافية إن كان المطلوب تحريكه مستقلًا.
- [ ] إطار البوابة كطبقات منفصلة: الضوء الخلفي، الفتحة/الداخل، الحافة الأمامية التي تحجب تشفير.
- [ ] صور جميع الوكلاء الاثني عشر، كل ملف منفصل وشفاف وباسم واضح.
- [ ] التصميم المرجعي لصفحة الوكلاء وصفحة اعتماد الفريق وصفحة مقارنة النموذجين والمصنع الحي.
- [ ] روابط/مفاتيح الخدمات في مدير أسرار آمن: Anthropic API، PostgreSQL، تخزين الملفات، sandbox، والنشر. لا تضع المفاتيح في البرومبت أو في الكود المصدري.


## أحدث توجيهات الهوية
الصورة ذات البطاقات 01/02/03 هي المرجع النهائي للألوان. استخدم صورة تشفير الشفافة بجانب كلمة «تشفير»، واجعل العناوين الرئيسية بتدرج عاكس مدمج مع الخلفية دون فقدان القراءة. الخلفية تتحرك وتتفاعل برفق مع الماوس، وتظهر النصوص البيئية كل خمس ثوانٍ تلقائيًا أو عند المرور عليها، بلا توهج يتبع المؤشر. راجع `03-docs/BRAND_MOTION_ADDENDUM_AR.md`.
