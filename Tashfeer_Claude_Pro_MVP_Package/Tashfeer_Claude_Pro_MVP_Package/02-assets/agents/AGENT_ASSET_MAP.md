- `product-manager` — مدير المنتج — `صورة مستقلة مطلوبة`
- `research-agent` — الباحث — `02-assets/agents/research-agent.webp`
- `requirements-analyst` — محلل المتطلبات — `صورة مستقلة مطلوبة`
- `ux-ui-agent` — مصمم UX/UI — `02-assets/agents/ux-ui-agent.webp`
- `software-architect` — معماري البرمجيات — `02-assets/agents/software-architect.webp`
- `frontend-agent` — المطور الأمامي — `02-assets/agents/frontend-agent.webp`
- `backend-agent` — المطور الخلفي — `02-assets/agents/backend-agent.webp`
- `database-agent` — قاعدة البيانات — `02-assets/agents/database-agent.webp`
- `qa-agent` — اختبار الجودة — `02-assets/agents/qa-agent.webp`
- `cybersecurity-agent` — الأمن السيبراني — `صورة مستقلة مطلوبة`
- `performance-agent` — الأداء — `صورة مستقلة مطلوبة`
- `devops-agent` — العمليات / DevOps — `صورة مستقلة مطلوبة`

## صور غير موجودة ضمن خريطة الصور المضمّنة الحالية

- `product-manager` — مدير المنتج
- `requirements-analyst` — محلل المتطلبات
- `cybersecurity-agent` — الأمن السيبراني
- `performance-agent` — الأداء
- `devops-agent` — العمليات / DevOps

لا تسمح باستخدام placeholder أو رسم CSS بدل صور الوكلاء في النسخة النهائية. إذا توفرت الصور الجديدة، استبدل/أكمل هذه الأصول وخذ الأسماء الفعلية في خريطة مركزية.
