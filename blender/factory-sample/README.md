# عينة المصنع في Blender

نماذج العينة البصرية للمصنع: الحزام، وقاعدة المحطة 01 وحاويتها الزجاجية، وقاعدة المنتج وحاويته وجهاز الشاشة. تُبنى كلها بسكربت، فتُعاد بأمر واحد بعد أي تعديل، ولا تحتاج عملًا يدويًا داخل البرنامج.

## الملفات

| الملف | ما هو |
| --- | --- |
| `build.py` | سكربت البناء: الأشكال والخامات والإضاءة وكاميرا المرجع، ثم الحفظ والتصدير |
| `export-line.mts` | يستخرج مسار خط الإنتاج من كود المصنع (`layout.ts`) إلى `line.json`، فيقع الحزام حيث تتوقع المحطات والمنتج |
| `line.json` | مسار الخط (481 نقطة)، ومواضع المحطة 01 والمنتج، وكاميرا المرجع |
| `factory-sample.blend` | المشهد الكامل: النماذج، والخامات، وثلاث إضاءات، والأرضية، وكاميرا المرجع (1672×941، زاوية رأسية 46°)، والخامات المضمّنة |
| `textures/plate_*.png` | خامات صفيحة الحزام المثقّبة: اللون، والـ normal، والـ ORM (الإظلال والخشونة والمعدنية) |
| `reference-render.jpg` | رندر Cycles من كاميرا المرجع، للتحقق من الملف فقط. المعيار هو المتصفح لا هذا الرندر |
| `../../public/models/factory/sample.glb` | ما يحمّله الموقع (قرابة 1 ميغابايت) |

## إعادة البناء

```bash
pip install bpy==5.2.3          # Blender نفسه كوحدة Python؛ يمكن أيضًا التشغيل داخل Blender 5.2
node --experimental-strip-types blender/factory-sample/export-line.mts   # فقط إذا تغيّر مسار الخط في layout.ts
python3 blender/factory-sample/build.py            # يحفظ .blend ويصدّر GLB
python3 blender/factory-sample/build.py --render   # ويضيف رندر Cycles من كاميرا المرجع
```

## ما يأتي من Blender وما يضبطه الموقع

- **من Blender:**
  - الأشكال كلها:
    - مقطع الحزام: حافتان مستديرتان مرتفعتان 4 سم، وحافة داخلية مائلة، وصفيحة، وأغطية للطرفين، وشريطا نيون على الوجهين الخارجيين؛
    - القاعدتان: مستطيل بزوايا مستديرة وحواف علوية وسفلية مشطوفة؛
    - أنبوب النيون: يتبع محيط القاعدة على سطحها؛
    - الحاويتان: زجاج مجوّف بجدار خارجي وداخلي سماكته 3.5 سم وحواف مستديرة؛
    - جهاز الشاشة: لوح بزوايا مستديرة، وعلى وجهه سطح الشاشة بإحداثيات UV.
  - الإحداثيات (UV) وخامات الصفيحة.
  - خامات PBR للأجزاء الداكنة (طبقة لمعان clearcoat) وللزجاج (transmission = 1، وIOR = 1.5، وخشونة 0.02).
- **من الموقع:**
  - **ألوان النيون:** تتبع حالة المحطة (انتظار، عمل، اكتمال).
  - **صفحة النموذج المعتمد على الشاشة:** تتطور مع المحاكاة.
  - **إضاءة الحواف على الزجاج:** طبقة fresnel.
  - **نسخة المستوى الخفيف:** زجاج دون نفاذ، وخامات قياسية.

## ملاحظة الزجاج

اختُبر الزجاج داخل المتصفح بنسخة Three.js التي يستعملها المصنع:
- **نفاذ 1 مع شفافية ألفا 0.15 (ملف الإثبات الأول):** يختفي الزجاج تقريبًا. Three.js يضرب اللون النهائي في الألفا، فتبهت الانعكاسات مع الجسم. لم يضِع النفاذ نفسه.
- **نفاذ 1 مع ألفا 1 (المصدَّر الآن):** يظهر الزجاج بحوافه وانعكاساته وما خلفه. لذلك صُدِّر الزجاج بألفا كاملة.
- **قيد:** الزجاج النافذ يُظهر خلفه الأجسام المعتمة فقط. لذلك صار محتوى المحطة معتمًا: حواف مضيئة ولوحات مقصوصة بدل الشفافة.
