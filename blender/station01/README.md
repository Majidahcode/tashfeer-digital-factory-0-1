# المحطة 01 وحدها — Blender

نموذج المحطة 01 مبنيًّا على نسب الصورة المرجعية، لصفحة المراجعة `/factory/station-01`. لا يستعمله المصنع بعد؛ المصنع ما زال على `blender/factory-sample`.

```bash
python3 blender/station01/build.py            # يحفظ station01.blend ويصدّر public/models/factory/station01.glb
python3 blender/station01/build.py --render   # ويضيف render.jpg (Cycles، للاطلاع فقط)
```

## المقاسات المأخوذة من المرجع

| الجزء | المقاس |
| --- | --- |
| القاعدة | 2.75 × 1.45 م، وارتفاعها 0.62 م، وأطرافها مستديرة (نصف قطر 0.55 م)، وحول سطحها حافة بارزة |
| الحاوية | 2.0 × 1.42 م، وعمقها 0.70 م (عرضها نحو 0.72 من عرض القاعدة، وارتفاعها نحو 0.72 من عرضها) |
| زجاج الحاوية | زوايا الإطار الأمامي مستديرة (0.10 م)، وحوافها مشطوفة شطفًا صغيرًا (1.2 سم)، وجدارها 2.8 سم بقشرتين داخلية وخارجية |
| النيون | خط حول قدم الزجاج، وشرطة على واجهة القاعدة |
| المحتوى | هيكل 2×2×2 من أنابيب مضيئة (خلايا 23 سم)، مدار 15° ليظهر عمقه، مع قائمتين رقيقتين على الجانبين |

يتحقق السكربت من أن المحتوى، بعد دورانه، لا يخترق جدران الزجاج.
